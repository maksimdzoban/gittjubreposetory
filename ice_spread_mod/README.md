# ❄️ Ice Spread Mod — Minecraft Forge 1.16.5

## Що робить цей мод?

Все навколо гравця поступово вкривається **звичайним льодом** (Ice), а через деякий час лід перетворюється на **пресований лід** (Packed Ice)!

- 💧 Вода → Лід (Ice)
- 🌍 Поверхня блоків → вкривається льодом зверху
- ⏱️ Звичайний лід → Пресований лід (через ~20 секунд за замовчуванням)

---

## Встановлення

### Вимоги
- Minecraft **1.16.5**
- Minecraft Forge **36.1.2+**
- Java **8** або **11**

### Кроки
1. Встанови [Minecraft Forge 1.16.5](https://files.minecraftforge.net/)
2. Скопіюй `icespread-1.0.0.jar` у папку `.minecraft/mods/`
3. Запусти гру!

## Компіляція з вихідного коду

### Вимоги для збірки
- JDK 17
- Gradle (або використовуй `gradlew`)

### Кроки
```bash
# Клонуй або розпакуй проект
cd icespread-mod

# Генерація Eclipse/IntelliJ проекту (опційно)
./gradlew genEclipseRuns
./gradlew genIntellijRuns

# Збірка .jar файлу
./gradlew build

# Файл буде у: build/libs/icespread-1.0.0.jar
```

### Запуск тестового клієнта/сервера
```bash
./gradlew runClient
./gradlew runServer
```

## Конфігурація

Після першого запуску файл конфігурації з'явиться у:
`.minecraft/config/icespread-common.toml`

```toml
[Ice Spread Settings]
    # Як часто (в тіках) відбувається поширення льоду. 20 тіків = 1 секунда.
    # Діапазон: 1-200, За замовчуванням: 10
    iceSpreadInterval = 10

    # Радіус навколо гравця де заморожуються блоки.
    # Діапазон: 1-20, За замовчуванням: 5
    iceSpreadRadius = 5

    # Тіки до того як звичайний лід стане пресованим (20 тіків = 1 сек)
    # Діапазон: 20-72000, За замовчуванням: 400 (20 секунд)
    packedIceDelay = 400

    # Максимальна кількість блоків що заморожуються за один тік.
    # Діапазон: 1-50, За замовчуванням: 5
    maxBlocksPerTick = 5

    # Чи ставити лід на поверхню твердих блоків.
    # За замовчуванням: true
    freezeAir = true

    # Чи перетворювати воду на лід.
    # За замовчуванням: true
    freezeWater = true

    # Чи поширювати лід навколо гравців.
    # За замовчуванням: true
    spreadFromPlayers = true
```

## Як працює мод

```
Гравець переміщується
        ↓
Кожні N тіків (за конфігом) перевіряється радіус навколо гравця
        ↓
Знаходить блоки води → замінює на Ice (Лід)
Знаходить повітря над твердою поверхнею → ставить Ice (Лід)
        ↓
Запам'ятовує час коли поставив кожен блок льоду
        ↓
Через packedIceDelay тіків: Ice → Packed Ice (Пресований лід)
```
